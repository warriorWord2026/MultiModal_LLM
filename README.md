# Автоматизированная научная библиотека с семантическим поиском (RAG)

Асинхронное On-Premise приложение на FastAPI и Qdrant для защищенного оффлайн-поиска и генерации ответов по локальной базе документов.

## 🛡️ Особенности информационной безопасности
- **Строгий Air-Gapped режим:** Переменная окружения `TRANSFORMERS_OFFLINE=1` полностью блокирует внешние сетевые запросы к серверам Hugging Face.
- **Локальный кэш моделей:** Все веса нейросетевых моделей (SBERT/BERT) изолированы внутри локальной директории `sbert_model_cache/` и монтируются в контейнер оффлайн.
- **Постоянное хранение данных:** Индексы и точки Qdrant изолированы на хост-машине в папке `qdrant_data/` для персистентного хранения.

## 🛠️ Архитектура и Стек
- **Backend:** Python 3.10+, FastAPI, Pydantic v2 (строгая валидация JSON), httpx (асинхронный клиент)
- **Векторный поиск:** Qdrant (индексация по метрике косинусного сходства)
- **Оркестрация:** Docker, Docker-compose
